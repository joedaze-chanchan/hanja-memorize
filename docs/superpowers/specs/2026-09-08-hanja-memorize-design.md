# 한자 외우기 교육 웹앱 — 설계 (2026-09-08)

## 목적
`영어 교육`(알파벳 따라쓰기) 앱과 같은 형태로, 모바일 브라우저에서 혼자 한자를 외우는 교육 프로그램.
획순 시범과 따라쓰기로 손에 익히고, 훈음↔한자 4지선다로 기억을 확인하며, 시험으로 실력을 잰다.

## 범위
- 한자능력검정시험(한국어문회) 8급 50자, 7급Ⅱ 50자. 각 글자에 훈·음·예시 단어·발음 mp3.
- 획 데이터는 hanzi-writer-data(Make Me a Hanzi 기반)의 획 중심선을 0~100 좌표로 변환. 敎는 자형이 없어 教 사용.
- 참여자 프로필·이어하기·따라 쓰기 횟수 설정은 영어 앱과 동일 (profiles.js, progress.js 재사용, 저장 키만 `hanja-*`).
- 학습 기록은 localStorage (기기 단위).

## 구성 (정적 웹앱, 빌드 없음)
| 파일 | 역할 |
|---|---|
| `hanja.js` | RAW 목록 `[한자, 훈, 음, 예시 단어, 읽기]` → `HANJA[ch] = { hun, eum, word, wordKo, level, strokes }` |
| `strokes.js` | `tools/fetch_strokes.py`가 만든 획 중심선 (자동 생성) |
| `tracer.js` | 영어 앱의 판정 엔진 그대로 (획 굵기 8, 허용 반경 최소 32px) |
| `app.js` | 참여자·대문·한자 고르기(급수 탭)·연습 화면 |
| `quiz-logic.js` | makeChoices(같은 급수, 훈음 겹침 방지), memorizeOrder, examQuestions, 점수 |
| `memorize.js` | 외우기 진행 (PHASES: 훈음 고르기 → 따라 쓰기 → 한자 고르기) |
| `exam.js` | 시험 진행 (20문제, 합격 70점, 기록판) |
| `pad.js` | 외우기 쓰기 판 (TracePad) |

## 화면 흐름
0. 참여자 고르기 → 첫 실행이면 따라 쓰기 횟수 설정(1~5, 기본 3).
1. 대문: 1 한자 따라쓰기(★ 완료 수) · 2 한자 외우기(외운 한자 수) · 3 한자 시험(최고 점수).
2. 한자 따라쓰기: 급수 탭(8급/7급Ⅱ) → 5열 격자(한자 + 훈음, 완료 별) → 연습.
   - 연습: 큰 한자 + 훈음 + 🔊, 급수·획수·예시 단어. 캔버스에 십자 점선 안내, 시범(파란색) 후 따라쓰기.
   - 획 진행 점(작게, 줄바꿈)과 "1/3번째 · 3/16획". 오답 3회 연속이면 시범 재생. 설정 횟수만큼 반복 후 완료.
   - 이어하기: 글자·회차·완료 획 수 저장 (영어 앱과 동일).
3. 한자 외우기: 급수(8급/7급Ⅱ/전체) 선택 → 섞은 순서로 글자마다 세 단계.
   - ① 한자 보고 훈음 4지선다 ② 훈음 보고 획순 따라 쓰기(쓰기 판, 발음 재생) ③ 훈음 보고 한자 4지선다.
   - 점수: 한 번에 맞힘 10, 틀린 뒤 맞힘 5, 따라 쓰기 완료 10. 보기 오답은 빨갛게 비활성, 다시 고름.
   - 한 글자의 세 단계에서 보기를 한 번도 안 틀리면 MemoryStore에 '외운 한자'(mastered). 대문·메뉴에 외운 수 표시.
   - 이어하기: 급수·순서·번째·단계·점수를 단계마다 저장. 메뉴 배너 "8급 · 12/50번째 · 120점 → 이어서 하기".
   - 끝: 점수, 안 틀린 글자 수, 급수별 최고 점수(`<id>-memo`).
4. 한자 시험: 급수 선택 → 20문제(한자→훈음, 훈음→한자 번갈아, 글자 중복 없음), 문제당 5점.
   - 답을 고르면 정답을 초록으로 표시하고 0.8초 뒤 다음. 다시 고르기 없음.
   - 끝: 점수, 맞힌 수, 합격(70점 이상)/불합격, 기록판 순위(BoardStore `hanja-exam-board`, 참여자 공통), 틀린 한자 목록.
